Note Link - Gestor de Enlaces Personalizable 📌

[![Deploy](https://img.shields.io/badge/LIVE%20DEMO-%20%F0%9F%94%97%20WEB-blue)](https://note-link-89bce.web.app/)



Gestor intuitivo para organizar recursos digitales mediante tarjetas personalizables. Ideal para crear catálogos de juegos, listas de compras, bibliotecas virtuales y más.
✨ Características Clave

    Personalización Total:

        Títulos editables

        Enlaces externos

        Imágenes desde tu dispositivo

        Diseño adaptable con Tailwind CSS

    Gestión Inteligente:

        Eliminación rápida con iconos integrados

        Almacenamiento persistente con Firebase

        Interacción fluida con React

    Optimización Profesional:

        SEO integrado

        Lazy Loading

        Diseño 100% responsive
